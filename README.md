# Русский голосовой пак споттера для iRacing

Неофициальный пак с женским голосом для русскоязычных пилотов. Споттер подсказывает, с какой стороны соперник, предупреждает о флагах и смене погоды, сообщает о топливе, шинах и повреждениях. У части сообщений есть несколько вариантов озвучки.

Базовый пак проверен в игре. В релиз вошли **1 033 озвученные строки**, включая **187 дополнительных вариаций**.

[▶ Послушать споттера · 18 секунд](https://cdn.jsdelivr.net/gh/VitaliyNig/Custom_Spotter@main/demo/Russian-Lisa-v1.0.mp3) — от «Машина слева» до клетчатого флага и поздравления с победой.

## Скачать и установить

**[Скачать аудиопак v1.0 для iRacing](https://github.com/VitaliyNig/Custom_Spotter/releases/download/v1.0/RU-Spotter-1.0.zip)**.

1. Скачай установочный архив по ссылке выше.
2. Распакуй папку `Russian-Lisa` в `<папка iRacing>\sound\spcc\`. Проверь, что файлы `.wav` и `spmsg.txt` лежат непосредственно внутри папки пака.
3. В настройках звука iRacing открой **AI Spotter Options → Voice Pack** и выбери **Russian-Lisa**.
4. Перезапусти iRacing.

## Голос и лицензия

Озвучка создана в ElevenLabs голосом Lisa из Voice Library. Проект не связан с iRacing.com Motorsport Simulations.

Аудиопак можно свободно распространять.

## English

An unofficial Russian-language spotter voice pack for iRacing, voiced with Lisa from the ElevenLabs Voice Library. The base pack has been tested in game. [Download the v1.0 voice pack](https://github.com/VitaliyNig/Custom_Spotter/releases/download/v1.0/RU-Spotter-1.0.zip).

[Listen to the 18-second voice demo](https://cdn.jsdelivr.net/gh/VitaliyNig/Custom_Spotter@main/demo/Russian-Lisa-v1.0.mp3).

To install a release, extract the pack folder into `<iRacing>\sound\spcc\`, select it under **AI Spotter Options → Voice Pack** in the audio settings, and restart iRacing.

You may freely redistribute the audio pack.
